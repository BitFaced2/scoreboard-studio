TMS SCOREBOARD STUDIO 0.5.0 - INTERNAL USE

START

Extract the portable ZIP and open ScoreboardStudio.exe. The Windows x64 build
bundles .NET; no separate .NET installation is needed. The app starts with no
source or fields, and outputs stopped.

UPDATE THE APP

Use Check for updates in the bottom bar, then Download update and Install and
restart. Stop NDI outputs and unlock editing first. Save unsaved setup changes
when prompted. The verified update replaces program files in the same folder;
existing shortcuts, saved setups and recordings stay in place. The app reopens
the saved setup with outputs stopped. Reconnect live sources and set stabilization
again as needed. Internet access and a writable app folder are required.

Versions older than 0.5.0 need one final manual GitHub ZIP download to get this
feature. No uninstall is needed. Failed downloads do not change the app; ordinary
installation write failures restore the previous files. Updates are never automatic.

LOAD YOUR FOOTAGE

Click Load image or video and choose your own scoreboard photo or recording.
No samples are included. Images: PNG, JPEG or BMP. H.264 MP4 is recommended
for video; other video formats depend on the codecs available in Windows.
Recordings play automatically with audio muted. Pause / Play, Restart and
Loop video controls appear below the filename. Pausing holds the last frame.
If looping is off, the final frame remains until you restart the recording.

The first source in a fresh app session gets automatic field boxes once.
After that, they stay fixed. Click + Draw a field, then drag a rectangle to add
a box. Select a box and click Remove selected field to delete it. Editing,
deleting all fields, reconnecting or looping never restarts automatic placement.
Load setup restores your crops, including an intentionally empty field list.
To rescan explicitly, use Find fields > Replace fields with suggestions.
Save setup remembers the selected image or video by relative path. Copy the
media with the setup when moving computers. Files are not embedded in layouts.

PREPARE THE FIELDS

For an angled camera, use Fields > Straighten camera, place the four numbered
corners, choose the corrected size and click Apply. Leave room for changing digits.
Name each field and draw a box around any field that was missed.
Find fields provides suggestions you can review and accept explicitly.
The corner editor freezes the picture. Drag a dot or label directly, or select
a corner and use arrow keys to fine-tune (Shift = 10 pixels).

Straightening does not delete fields. To remove one, select it under Your
fields and click Remove selected field at the bottom left. After changing
the view, resize the remaining boxes or Find fields > Replace fields with suggestions
to rebuild them. Save setup when finished.

Open Cleanup and compare the original and cleaned pixels. Use Bright colors
for red/amber LEDs on dark panels, or White highlights for white digit cores
surrounded by colored glow. Adjust Background cutoff and Edge softness.

CAMERA STABILIZATION

After setup, click Stabilize camera to capture a reference. Review the crops,
then start outputs. Small shifts, rotation and zoom are corrected beneath your
fixed boxes. Tracking needs visible detail around the board. Tracking loss
clears outputs until the reference is found again. For a large camera move,
stop stabilization, realign the board and fields, then enable it again.
Set reference explicitly captures a new view and stops outputs for review.
Changing sources or loading a setup disables stabilization; references are
session-only. Stabilization does not run field detection.

WINDOW AND DIAGNOSTICS

Use the Windows title bar or header buttons to minimize/maximize/restore.
Drag the window edges to resize; smaller windows scroll to reach the controls.
Error logs and attempted UI-crash setup recovery are stored in:
%LOCALAPPDATA%\TMS Scoreboard Studio\Diagnostics

SEND TO VMIX

1. For a live source, choose an NDI feed and click Connect. For a recording,
   use Load image or video directly; vMix playback is not required.
2. Enable the desired fields and click Start NDI outputs.
3. In vMix, Add Input > NDI for each Scoreboard - <field name> source.
4. Position those inputs as layers over your scorebug. They include alpha.
5. Save the vMix preset separately. Use Lock for live to protect app settings.

The source dropdown lists NDI feeds only. Cameras and capture cards must be
added in vMix and sent over NDI first. An empty dropdown is normal when using
a local image or video and does not affect file playback.

An installed 64-bit NDI runtime is required for NDI input/output. A standard
vMix installation can supply it; no NDI runtime or vMix is bundled. Local
image/video processing works without NDI. Still-image streams include STILL
in their names. NDI also includes the computer name.

IF SOMETHING DOES NOT WORK

- Video will not open: use a Windows-supported H.264 MP4 with a video track.
- No NDI sources: enable NDI at the sender, then Refresh. Check connectivity.
- Missing media: use Load image or video to locate it, then save your setup.
- NO SIGNAL: check the sending source. After 1.5 seconds without new NDI
  frames, fields clear to transparency and resume when frames return.
- Glow remains: raise cutoff or try White highlights. If digits vanish,
  lower the cutoff and check the original crop for missing detail.
